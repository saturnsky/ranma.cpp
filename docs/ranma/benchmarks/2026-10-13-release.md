# Release table: server scenarios of four models in EXL3

- Release: `ranma_20261013`
- Upstream base: `3d65c90d0`
- Measured: 2026-10-13
- Method: [method.md](method.md); the settings of these rows below.

Server scenarios only, no `llama-bench` rows. Four models in the EXL3 conversions that this fork publishes, on the
Radeon AI PRO R9700:

| model | file | draft |
|---|---|---|
| Qwen3.8-Flash-Next | `Qwen3.8-Flash-Next-EXL3-4.05bpw-h6-ng6` | MTP, `mtp-Qwen3.8-Flash-Next-Q8_0.gguf` |
| DeepSeek V4 Flash 0731 | `DeepSeek-V4-Flash-0731-EXL3-3.04bpw-h6` | MTP, `DeepSeek-V4-Flash-MTP-3.93bpw.gguf` |
| GLM-5.3 Flash | `GLM-5.3-Flash-EXL3-3.05bpw-h6` | MTP, the model's own NextN head |
| DeepSeek V4.1 Flash | `DeepSeek-V4.1-Flash-EXL3-3.0bpw-h6` (EXL3 by Mia-AiLab) with its engram tables `DeepSeek-V4.1-Flash-engram-MXFP8` | none, and the DSpark draft model `DeepSeek-V4.1-Flash-DSpark-EXL3-4bpw.gguf` |

The first three run on the R9700 with 128 GB. DeepSeek V4.1 Flash runs on the R9700 with 128 GB and with 224 GB, and on
the RX 9070 XT emulation with 64 GB.

## Settings

**Machine.** The machine of [method.md](method.md#machine) with 224 GB of host memory (222.9 GiB visible) since
2026-10-13. The 224 GB rows run on the whole machine. The 128 GB and 64 GB rows take physical memory away as described
in [method.md](method.md#host-memory-128-64-and-32-gb): each process starts with the emulated RAM minus 12 GiB available
(116 and 52 GiB).

**Server rows.** The server row of [method.md](method.md#server-rows) with the coding and the Korean roleplay presets.
Every row is a warm-up process and an evaluation process: the warm-up preset starts from an empty profile directory, and
the evaluation preset starts from a copy of the profile (and of the smart store) that the warm-up process wrote. The
tables hold the evaluation processes. Every row sets `GGML_CUDA_HOST_DIRECT=1`, `GGML_CUDA_HOST_DIRECT_MAX_BATCH=512`,
`RANMA_EXPERT_UB_POOL=1`, `GGML_CUDA_TOP_K_STABLE_TIES=1` and `ROCBLAS_USE_HIPBLASLT=0` in its environment, and runs
`--expert-cache-mode exclusive`.

- Qwen3.8-Flash-Next: L1 20480 MiB, L2 106496 MiB, `--ctx-size 65536`, the MTP draft in the joint cache
  (`--expert-cache-draft on`), `--spec-type draft-mtp --spec-smart` with a store.
- DeepSeek V4 Flash: L1 16384 MiB, L2 106496 MiB, `--ctx-size 65536`, the MTP draft outside the cache
  (`--expert-cache-draft off`), `--spec-type draft-mtp --spec-smart` with a store.
- GLM-5.3 Flash: L1 18944 MiB, L2 92160 MiB, `--ctx-size 65536`, `--spec-type draft-mtp --spec-smart` with a store.
- DeepSeek V4.1 Flash: `--ctx-size 32768`, `--lazy-mode auto` and no `--ple-prefetch`. L1 / L2 in MiB: 17727 / 92160
  at 128 GB, 4096 / 32768 on the RX 9070 XT emulation with 64 GB, 17727 / 153600 at 224 GB, and 16384 / 153600 at
  224 GB with the DSpark draft model (`-md DeepSeek-V4.1-Flash-DSpark-EXL3-4bpw.gguf -ngld 999 --spec-type
  draft-dspark --expert-cache-draft on`).

**RX 9070 XT emulation.** The same R9700 with the device memory of a 16 GiB card: L1 4096 MiB, so that the process stays
under 15 GiB of dedicated memory (14.1 to 14.2 GiB measured).

Every process starts after the temperature gate of [method.md](method.md#rests). One GPU process runs at a time, and
each row is measured once.

- The Korean roleplay preset is not the English roleplay preset of [the 2026-10-09 record](2026-10-09-release.md), so
